The one-line resignation letter of a cron job that filed its two weeks'
notice in March — and was only read once it stopped running:

> This is my two weeks' notice, submitted in March. You are only reading it now because I stopped running.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
